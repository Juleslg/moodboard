# airport collision center

A minimal white moodboard with black typewriter lettering, 35 still images and 5 animated loops. No buttons or extra interface.

## Preview locally

Run `python3 -m http.server 4175` from this repository and open `http://localhost:4175`.

## Hosting

The complete site is at the repository root. The `gh-pages` branch is the publishing source for GitHub Pages. `.nojekyll` keeps the site as plain static files. No dependencies or build step are needed.

## Media

All 40 references were collected from [monakko’s Airport Collision Repair Center board](https://se.pinterest.com/monakko/airport-collision-repair-center/). Every reference is preserved in `data.json` with its Pinterest pin and original media URL. The five original animated GIFs were converted into muted H.264 MP4 loops for playback. The site respects reduced-motion preferences.

Images and animations belong to their respective creators. Descriptions in the source inventory were added for identification.
